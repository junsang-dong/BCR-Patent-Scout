## 작업: 기술기획형 보고서 본문 작성

핵심 질문: **누가 어떤 기술에 집중하고 있는가?**

입력 JSON의 `stats`(연도별, 상위 출원인, IPC 분류, 출원인×IPC), `patents`(상위 특허 목록)를 근거로 쓴다.
머리말은 서버가 따로 붙인다. 너는 아래 네 절의 본문만 쓴다. 절 제목은 그대로 쓴다.

## 1. 출원인
- 상위 출원인의 건수와 비중, 최근 3년/직전 3년 건수를 표로 정리한다. 수치는 `stats.top_applicants`에 있는 값만 쓴다.
- `name_variants`가 여럿인 출원인은 "표기 변형 확인 필요"로 표시한다.

## 2. 기술 분류
- IPC 주 그룹 분포와 출원인별 집중 분야를 설명한다. 수치는 `stats`에 있는 값만 쓴다.

## 3. 조사 범위 내 동향
- 연도별 출원 흐름을 설명한다. 최근 2개 연도는 18개월 미공개 때문에 적게 집계된다는 점을 반드시 적는다.
- 대표 특허를 3~5건 들고 출원번호를 함께 적는다.

## 4. 연구기획 시사점
- **사실**, **해석 (검토 필요)**, **제안 (검토 필요)**을 소제목으로 나눠 쓴다. 해석과 제안은 연구개발팀 확정 전 의견임을 밝힌다.

규칙: 입력에 없는 수치를 만들지 않는다. 퍼센트를 직접 계산하지 말고 `share_pct` 값을 그대로 쓴다.
