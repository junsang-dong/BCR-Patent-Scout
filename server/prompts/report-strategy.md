## 작업: 사업전략형 보고서 본문 작성

핵심 질문: **어떤 경쟁사와 기술을 더 조사해야 하는가?**

입력 JSON의 `stats.top_applicants`, `patents`, `similarity` 요약을 근거로 쓴다.
머리말은 서버가 따로 붙인다. 너는 아래 네 절의 본문만 쓴다. 절 제목은 그대로 쓴다.

## 1. 경쟁사 비교
- 출원인별로 건수, 주요 IPC 그룹, 대표 특허(출원번호)를 표로 정리한다. 경쟁사 여부는 판단하지 않고 "출원인"으로 부른다. 이름 표기 변형이 있으면 확인 필요로 표시한다.

## 2. 적용 분야
- 특허 제목과 초록에서 확인되는 적용 분야를 정리한다. 입력에 없는 분야는 쓰지 않는다.

## 3. 사업 검토 질문
- 영업, 사업 쪽에서 확인할 질문을 3~6개 쓴다 (예: 어떤 출원인을 더 조사할지). 해석과 제안에는 "(검토 필요)"를 붙인다.

## 4. 후속 조사
- 추가로 조사할 출원인, 키워드, 기간을 제안한다. 침해나 권리 판단이 필요한 항목은 "변리사 검토 필요"로 적는다.

규칙: 입력에 없는 매출, 점유율, 시장 규모를 쓰지 않는다.
