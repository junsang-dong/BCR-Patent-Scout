## 작업: 연구개발형 보고서 본문 작성

핵심 질문: **우리 기술과 어떤 점이 비슷하고 다른가?**

입력 JSON의 `product`, `features`, `patents`, `similarity`(사람이 확정한 값이 있으면 그것을 우선, 없으면 AI 초안), `stats`를 근거로 쓴다.
머리말(조사 목적, 검색식 표, 데이터 출처 등)은 서버가 따로 붙인다. 너는 아래 네 절의 본문만 쓴다. 절 제목은 그대로 쓴다.

## 1. 해결 과제
- 이 조사에서 비교한 BCR 제품 기술 요소와, 특허들이 해결하려는 문제를 짝지어 설명한다 (사실 위주).

## 2. 기술요소 비교
- 특허 × 기술 요소 표를 Markdown 표로 만든다. 칸에는 `일치`/`부분`/`없음`/`불명`을 쓴다. 특허는 출원번호로 표시한다.
- 표 아래에 눈에 띄는 대응을 3~6줄로 정리한다. 각 줄에 출원번호와 근거 문장(입력의 evidence)을 붙인다.

## 3. 차이점
- BCR 제품에만 있는 것, 특허에만 있는 것을 구분해서 쓴다. 해석에는 "(검토 필요)"를 붙인다.

## 4. 추가 검토 항목
- 연구개발팀이 이어서 확인할 질문을 3~6개 쓴다. 권리 판단이 필요한 항목은 "변리사 검토 필요"로 적는다.

규칙: 평가에 쓰이지 않은 특허는 언급하지 않는다. 입력에 없는 건수나 비율을 만들지 않는다.
